# Project 1 – Threat Model

## Objective
Identify and assess identity-related threats in the SecureNova AI platform.

## Scope
This project covers:
- Human users
- AI agents
- OAuth M2M clients
- LLM API keys
- RAG pipeline services
- MCP server identities

## Activities
1. Identity inventory
2. STRIDE threat analysis
3. Data-flow diagram
4. Attack tree analysis
5. Risk scoring
6. MITRE ATLAS mapping
7. Risk register

## Tools
- OWASP Threat Dragon
- draw.io
- Microsoft Excel
- MITRE ATLAS
- GitHub
